  1. ตั้งชื่อ Repository (เช่น db-bigdata-quiz) เลือก Public แล้วกด Create

  3. ไปที่ Settings → Pages เลือก Branch เป็น main แล้วกด Save เพื่อรับลิงก์เว็บ
